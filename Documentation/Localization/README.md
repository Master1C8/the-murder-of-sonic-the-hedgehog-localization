# English localization source package

This directory contains a deterministic, translation-ready English source
package for Steam App ID `2324650`, build `20535215`, game version `1.01`,
Unity `2021.3.9f1`. The installed Steam game is read-only input; extraction
does not modify or launch it.

## Translator inputs

- `Source/en/source.en.json`: canonical 3,547-unit source with stable IDs,
  source paths, scene/UI context, editorial state, and protected tokens.
- `Source/en/source.en.csv`: the same units in spreadsheet-friendly form.
- `Source/en/batches/`: 29 smaller context packages grouped by story section
  or UI surface.
- `Source/en/translation-template.json`: locale-neutral blank overlay. Copy it,
  set `targetLocale`, and author only the values under `units`.
- `Source/en/images/`: 72 lossless PNG exports preserving their Unity source
  hierarchy. `image-review.json` identifies 10 images that require localized
  redraws and 15 whose numbers/symbols must remain exact.
- `story.en.json`: normalized raw Ink JSON for engineering and reinsertion.

`inventory.json` is the complete engineering inventory. In addition to the
translator corpus it records 706 managed-code string candidates, of which 7
runtime UI literals are confirmed in the corpus, 17 display-only speaker
labels, 6 display-only establishing-shot titles, plus 17 font/SDF assets.
Unconfirmed code strings remain separate and must not be translated blindly.
`extraction-report.json` records tool versions, hashes, and counts.

The existing `ru.manual.json` is a work-in-progress authored locale. The
extractor never creates, rewrites, or clears target-locale manual/overlay files.
`ru.overlay.json` is a derived file and may be rebuilt from the manual layer.
No wording in any language is generated by the tooling.

Ink speaker prefixes such as `Amy::`, rich-text tags, format placeholders, and
Ink command shells are protected runtime syntax. Translate the source text,
not the stable ID or protected tokens. The binding contract for character and
location labels is [RUNTIME_IDENTIFIERS.md](RUNTIME_IDENTIFIERS.md).

Editorial acceptance for every locale follows
[AUDIT_WORKFLOW.md](AUDIT_WORKFLOW.md): one complete semantic audit, followed
by a clean dependency-aware diff audit and a full deterministic final gate.
This avoids repeated full model rereads while preserving traceable coverage of
every source unit and every changed result.

Locale-specific text fitting belongs in the optional `layoutOverrides` object,
keyed by the same stable unit ID. Only allowlisted visual metrics may be set;
text, IDs, control syntax, asset keys, and images must never be changed to solve
a fit problem. The current schema supports `m_fontSize` and `m_fontSizeBase`
for Addressables and `level0` TMP labels. The Russian runner HUD uses this
mechanism to keep `КОЛЬЦА` on one line without abbreviating the translation;
the same mechanism keeps the save-slot location and timestamp on separate
lines. Scene overrides use verified offsets relative to the padded end of
`m_text` and reject unexpected serialized values before patching.

## Re-extract

Install UnityPy outside the repository, expose it through `PYTHONPATH`, and
ensure `monodis` is available for managed-code inventory:

```sh
PYTHONPATH=/private/tmp/murder-sonic-unitypy \
  python3 Scripts/extract-localization-assets.py extract \
  --data-root "/path/to/The Murder of Sonic The Hedgehog.app/Contents/Resources/Data" \
  --output Documentation/Localization
```

Extraction is pinned by the source fingerprint in `inventory.json`. Repeat it
and review the diff if the Steam build changes.

## Validate the English package

```sh
python3 Scripts/extract-localization-assets.py validate-source \
  --inventory Documentation/Localization/inventory.json \
  --source-root Documentation/Localization/Source/en \
  --image-review Documentation/Localization/image-review.json
```

This verifies JSON/CSV/batch coverage, image presence and SHA-256, and the
human image-review classification against the exact candidate set.

## Compile and validate an authored locale

```sh
python3 Scripts/extract-localization-assets.py compile-overlay \
  --inventory Documentation/Localization/inventory.json \
  --manual Documentation/Localization/ru.manual.json \
  --output Documentation/Localization/ru.overlay.json

python3 Scripts/extract-localization-assets.py validate \
  --inventory Documentation/Localization/inventory.json \
  --overlay Documentation/Localization/ru.overlay.json \
  --allow-incomplete
```

The commands are locale-agnostic; Russian is only the current example.
`--allow-incomplete` is for work in progress. A release must validate without
it and separately pass font coverage, layout, reinsertion, runtime, and visual
QA. The `build-sharedassets` command writes only to a caller-selected output
directory and is intended for isolated temporary tests.

## Fonts

The reproducible nine-font Noto set, exact 30-locale corpus audit, source
hashes, licenses, and remaining complex-script gates are documented in
[`Fonts/README.md`](Fonts/README.md). Static glyph coverage passes for all 30
final overlays and image plans. This does not yet establish Arabic/Persian/
Hebrew bidi behavior, Arabic/Persian/Devanagari/Thai shaping, runtime
readability, or release readiness.
