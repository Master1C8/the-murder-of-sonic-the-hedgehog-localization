- Project: `/Users/antonkrutov/Desktop/The Murder of Sonic the Hedgehog Localization` on canonical `main`.
- Target: Steam App ID `2324650`; payload baseline build `20535215`, game `1.01`, Unity `2021.3.9f1`. Later Steam Build IDs are accepted when every touched game file remains hash-compatible with this baseline or with the verified prior VN Revival receipt.
- Coverage: all 30 canonical non-English VN Revival locales are editorially accepted and packaged with their prepared fonts. Each locale contains 3,547/3,547 translated text units with no missing runtime IDs.
- Selection: the user chooses the active locale in the installer. One application bundle contains all 30 variants; rerunning it safely switches the installed locale.
- Platform payloads: macOS and Windows each use one platform-specific `Assembly-CSharp.dll` delta with the same shared managed runtime and compressed external story/runtime data for all 30 locales. Ten prepared fonts are shipped once and the selected locale's font is privately registered at runtime. No Unity scene, story asset, Addressables bundle, catalog, inventory bundle, or texture is rebuilt. The macOS payload is 75,348,472 bytes (71.86 MiB), the universal app is 77,575,916 file bytes, and the distributable ZIP is 62,976,623 bytes (60.06 MiB).
- Safety: Steam library and manifest discovery, App ID validation, per-file update compatibility, permanent original backup, ownership checks, staging, recovery, and rollback remain mandatory. A changed Steam Build ID is not rejected by itself: exact original/payload/receipt SHA-256 values decide whether the shared assembly patch remains safe. If an update changes the managed source assembly, installation aborts before replacing game data and a refreshed patch is required. The legacy Windows Russian smoke-test layout is transactionally restored from its verified backups before the compact runtime is installed; any receipt, installed-file, or backup mismatch aborts without changing the game.
- Images: localized textures are deliberately deferred by owner instruction. `BuildManifest.json` records `imagesModified=false`; the ten text-bearing PNGs remain original English assets.
- Provenance: the French fan patch remains research-only and none of its files or wording are shipped.

- Runtime/visual status: every compressed story was verified by stable Ink path against all 3,335 canonical story translations, every locale data file was checked against all 212 non-story runtime units, and both managed assemblies pass Mono IL verification. The shared-runtime architecture has not yet received a fresh in-game visual pass, so prior screenshots are not claimed as proof for this new loader.
