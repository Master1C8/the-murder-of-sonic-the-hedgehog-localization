Выбранные `siteLocale` и `runtimeCode` записываются в транзакционную квитанцию `.vn-revival/fun.vnrevival.murder-of-sonic.languages/receipt.json`, которую должен читать общий Unity runtime-патч. Для всех локалей действует `Documentation/Localization/RUNTIME_IDENTIFIERS.md`: служебные ID и синтаксис неизменны, имена и заголовки переводятся только через display-only слой.
